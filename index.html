Group 1

扫描与查找

一遍扫过去就能解决的那一类
  • 01哈希用空间换「我见过你吗」的 O(1) 回答
  • 02双指针有序或对称结构里，两端 / 快慢协同收缩搜索空间
  • 03滑动窗口连续区间问题，右扩左缩维护一个「合法窗口」
  • 04栈与单调栈每个元素都在找「左/右第一个比我大的人」
  • 05二分查找不止搜位置，还能搜答案本身——前提是判定函数单调
Group 2

链表 · 树 · 堆

指针改写、递归填空、只关心第 K 个
  • 06链表只有指针改写和快慢指针两件事；画图 > 心算
  • 07树的遍历与递归一切树题 =「对当前节点做什么 + 递归左右」的填空
  • 08堆 / Top-K只关心第 K 个时，不排序，养一个大小为 K 的堆
Group 3

搜索与图

把状态空间走一遍
  • 09回溯做选择 → 递归 → 撤销选择；剪枝决定生死
  • 10图的 BFS/DFS网格也是图；visited 集合是命根子
  • 11拓扑排序「依赖关系」三个字出现就是它；入度为 0 进队列
  • 12并查集动态连通性——「这俩在不在一伙」
Group 4

预处理与排序后的结构

先加工数据，问题就变形了
  • 13前缀和一次预处理，之后区间和 O(1)；配哈希解「子数组和为 K」
  • 14区间先按起点排序，剩下的就是「重叠怎么办」
  • 15贪心先说出「局部最优不毁全局」的那个性质，再动手
Group 5

动态规划

先写状态定义，再写转移
  • 16一维 DPdp[i] 只依赖前几项；先写状态定义再写转移
  • 17二维 DP 与背包两个维度各自「取到 i / 容量 j」；背包 = 选或不选
  • 18子序列 DPLIS 两解法：O(n²) DP 与「耐心排序 + 二分」
