§1 Mental Model 一句话心智模型

先记住这一句

「依赖」两个字出现就是它：把入度为 0 的点放进队列，出队一个就给它的后继减一个入度，减到 0 再入队。

判环不需要额外逻辑：能出队的点数少于总点数，剩下的就卡在环里。这一条让「能不能修完所有课」和「给出一种修课顺序」变成同一段代码，只是返回值不同。

全章唯一的难点其实是建图方向。LeetCode 给的 [b, a] 意思是「修 b 之前要先修 a」，所以边是 a → b、indeg[b] += 1。方向反了代码照样能跑，只是答案整个是倒的。

看到什么，想到本章

分流条件 · 决策树同源

同样用队列，第 10 章的 BFS 队列里放的是「所有未访问的邻居」，本章队列里放的是「入度已清零的点」——入度这两个字是分界线。判环也要分清：有向图判环用拓扑（本章），无向图判环用并查集（第 12 章，union 返回 False 即成环）或 DFS 记父节点。只要遍历、不问顺序，回到第 10 章。

§3 Template 模板代码

可默写的那几行

■ 【骨架】 不变，闭着眼默写　■ 【插槽】 随题变化，写题前先问自己填什么

模板 A · Kahn 入度法本章唯一模板
from collections import deque

def topo_order(n, prerequisites):
    graph = [[] for _ in range(n)]          # 【骨架】邻接表:a -> b 表示"修完 a 才能修 b"
    indeg = [0] * n                         # 【骨架】入度 = 还欠几个前置
    for b, a in prerequisites:              # 【插槽】题目给的是 [课, 先修课],方向别搞反
        graph[a].append(b)
        indeg[b] += 1
    q = deque(i for i in range(n) if not indeg[i])   # 【骨架】所有零依赖的先入队
    order = []
    while q:                                # 【骨架】
        cur = q.popleft()                   # 【骨架】
        order.append(cur)                   # 【插槽】答案:顺序本身 / 只要个数
        for nxt in graph[cur]:              # 【骨架】
            indeg[nxt] -= 1                 # 【骨架】它少欠一个了
            if not indeg[nxt]:              # 【骨架】欠债清零才有资格入队
                q.append(nxt)               # 【骨架】
    return order if len(order) == n else [] # 【插槽】出队数 < n 就是有环
默写口诀：建图数入度、零入度入队、出队减邻居、计数判环。DFS 三色法（白/灰/黑）也能做，但入度法更好写也更好讲，阈值内只需要这一个。

§5 Pitfalls & Self-check 常见翻车点 + 自测

会写不等于不翻车

  1. 建图方向反了——[b, a] 是「先修 a 才能修 b」，边必须是 a → b。反了之后 207 依然返回 True（有向无环图反向仍无环），但 210 的顺序整个是倒的。
  2. 孤立点漏进入度表——入度数组必须按 n 开满，没有任何依赖的课也要以 0 入度进队列。只遍历 prerequisites 建表，会漏掉从未出现过的课号。
  3. 用异常或染色去判环——拓扑判环只需要 len(order) == n 这一句。写成递归 DFS 再捕获「重复访问」，既长又容易把「本次路径上」和「以前访问过」搞混。
  4. 以为拓扑序唯一——同时有多个零入度点时，顺序取决于出队次序。题目说「返回任意一种」就是这个意思；要求字典序最小时把队列换成小顶堆（第 08 章）。

自测 · 30 秒识别模式

30 秒识别Q1 · 2115 Find All Possible Recipes from Given Supplies：给一批菜谱、各自的原料表和你手上的现有原料，求最终能做出哪些菜（一道菜也可以是另一道菜的原料）。你的第一反应是哪个模式？

看答案

拓扑排序。「A 是 B 的原料」就是一条有向边，手上的现有原料是入度为 0 的起点，能被剥出来的菜就是做得成的。题面把「依赖」换了个说法而已——认出有向依赖这四个字，模板一行不用改。

30 秒识别Q2 · 802 Find Eventual Safe States：有向图中，从某点出发的所有路径最终都能走到终点（出度为 0 的点），求所有这样的安全点。你的第一反应是哪个模式？

看答案

拓扑排序。把图反向后，出度为 0 就变成入度为 0，能被剥掉的点就是安全的，剥不掉的卡在环里。「反向建图」是拓扑题的常见变形。

30 秒识别Q3 · 547 Number of Provinces：给一个 n×n 的矩阵表示城市之间是否直接相连，求「省份」（连通块）的个数。你的第一反应是哪个模式？

看答案

并查集，不是本章——图是无向的，问的是「谁和谁在一伙」而不是「谁在谁前面」。无向图没有入度这个概念，拓扑排序无从谈起。见 §2 分流条件与第 12 章。

每章自测都会混入恰好一道非本章题，防止「读哪章选哪章」的条件反射；题面也一律取自本章未收录的题，避免凭记忆而非凭信号作答。
