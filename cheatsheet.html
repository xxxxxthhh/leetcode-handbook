§1 Decision Tree 决策树

拿到题先问「数据长什么样」

├─ 数组 / 字符串　最常见的入口，先问「要在里面找什么」
│ ├─ 问「见过吗 / 出现几次 / 怎么归类」　→　01 哈希
│ ├─ 已排序，要找一对数、或首尾对称地比　→　02 双指针
│ ├─ 连续区间 + 约束，求最长 / 最短　→　03 滑动窗口
│ ├─ 连续区间 + 和恰好为 K、或多次查询区间和　→　13 前缀和
│ ├─ 要「下一个更大 / 更小」、或定长窗口的最值　→　04 栈与单调栈
│ ├─ 已排序找一个位置、或答案本身可以二分判定　→　05 二分查找
│ ├─ 输入是一堆 [start, end]　→　14 区间
│ └─ 每一步该选谁一眼就能看出，且不用回头改　→　15 贪心
├─ 链表　指针改写 + 快慢指针，两件事而已
│ └─ 节点要重新接线，或要找中点 / 判环　→　06 链表
├─ 树　对当前节点做什么 + 递归左右
│ └─ 二叉树 / BST 上的遍历、深度、路径、LCA　→　07 树的遍历与递归
├─ 图 / 网格　网格也是图；先问「问的是什么」
│ ├─ 连通块个数 / 面积，或最少步数（边权都是 1）　→　10 图的 BFS/DFS
│ ├─ 题面出现「先修 / 依赖 / 循环依赖」（有向）　→　11 拓扑排序
│ └─ 边一条条加进来，随时问「这俩在不在一伙」（无向）　→　12 并查集
└─ 没有明显结构：问最优值 / 方案数　到这一层就是「枚举还是递推」的选择
　 ├─ 要列出全部方案（数据规模很小）　→　09 回溯
　 ├─ 只关心第 K 个 / 前 K 个，或数据是流式的　→　08 堆 / Top-K
　 ├─ 要最优值 / 方案数，状态是一个下标　→　16 一维 DP
　 ├─ 状态是两个下标（两个序列、容量 × 物品）　→　17 二维 DP 与背包
　 └─ 子序列（可跳着取）的最长 / 最多　→　18 子序列 DP

叶子恰好 18 个，与 18 个模式一一对应——构建时程序化核对过覆盖率与唯一性。
